# Ponytail Skill

Mengaktifkan pemantauan otomatis (ponytail monitoring) pada model data, schema, dan integrasi backend. Menerapkan sinkronisasi database instan tanpa perlu memicu sinkronisasi manual saat terjadi modifikasi data.
